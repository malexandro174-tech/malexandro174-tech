## Основной проект — AI Automation & Portfolio Consultant

**Публичный RAG-консультант по AI-автоматизации и реализованным кейсам · v1.0.0**

Помогает посетителю описать задачу, найти похожие решения и проверить опыт по источникам. Объединяет векторный и текстовый поиск, проверяет цитаты в ответах, показывает до трёх релевантных кейсов и поддерживает уточняющие вопросы. Если подтверждения нет, сообщает об этом. Заявки из чата автоматически не отправляет.

**Стек:** Python, FastAPI, PostgreSQL / pgvector, BGE-M3, DeepSeek, Docker, JavaScript.

В опубликованной приёмке зафиксированы следующие результаты:

| Проверка | Результат и границы измерения |
| --- | --- |
| Контрольный набор после фиксации параметров | 19 из 20 синтетических сценариев пройдены — 2 октября 2026 |
| Фактические вопросы | 10 из 10 в том же наборе |
| Критические выдуманные утверждения | 0 в проверенном наборе |
| Время ответа | P95 — 5,50 с на 20 публичных запросах без кеша ответов |
| Локальная регрессия публичного кода | 69 тестов пройдены — 3 октября 2026; без подключений к рабочим сервисам |

Это результаты ограниченной тестовой выборки, а не гарантия точности на любых запросах. В одном неоднозначном сценарии не было ожидаемого уточнения; бизнес-эффект пока не измерен. Публичный код требует настройки интеграций для самостоятельного развёртывания.

## Подход к работе

Начинаю с конкретного процесса: откуда поступают данные, какой результат нужен, кто принимает решение и как проверить качество. Для AI-сценариев предусматриваю валидацию, обработку недостаточных данных и явные границы автоматических действий.

В портфолио разделяю работающие функции, тестовые сценарии и планы развития. Публичные метрики сопровождаю условиями измерения; подключение нового сервиса, сроки и стоимость оцениваю после уточнения задачи.
